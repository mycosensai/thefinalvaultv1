# The Final Vault v1

A clean new repository for an AI-driven auction house website.

## Features

- React + Vite + Tailwind CSS frontend
- AI-inspired buyer search simulation
- ProVerify human review workflow
- Auction item submission and inventory management
- Modern dark UI with responsive design

## Setup

1. Open `thefinalvaultv1` in VS Code.
2. Run `npm install`.
3. Start the site with `npm run dev`.

## Run

- `npm run dev` — Start development server
- `npm run build` — Build production bundle
- `npm run preview` — Preview production build

## Repository

This repository was created as a fresh project under `thefinalvaultv1` to deliver a consolidated code stack for the website.
